基本方式：

1. 下载或 clone 整个项目目录。

## 总体设计

- 仅使用匿名编号，不收集姓名、学号或其他身份信息。
- 编号可填写 `1`、`P01` 或其他简短匿名编号，不要求固定格式。
- 被试先阅读知情同意，再选择摄像头眼动或鼠标兜底。
- 三项实验顺序根据匿名编号轮换，减少固定顺序带来的练习和疲劳误差。
- 每项实验包含指导语、练习和正式试次。
- 每项实验单独向课程收数接口提交一次。
- 数据上传失败时，网页保留当前结果并允许下载 JSON 备份。

## 实验一：闪烁找不同

研究问题：空间线索能否改善闪烁范式中的变化觉察？

设计：

- 被试内条件：中性线索 10 试次，空间线索 10 试次。
- 空间线索中 80% 有效、20% 无效；中性线索不指向左右。
- 正式试次共 20 次，练习 2 次。
- 单试次最长 20 秒。
- 刺激采用程序化控制的面板场景，变化位置分为左、右半屏，变化类型包括颜色变化和出现/消失。

操作：

1. 先盯住中央注视点。
2. 观察线索和原图/空白/改图的循环。
3. 发现变化后立即按空格。
4. 用鼠标点击变化位置。

因变量：

- 是否发现变化。
- 发现时间。
- 点击位置是否正确。
- 中性线索与空间线索的发现率差、发现时间差。
- 眼动样本落在变化区域但未报告的“看了却没看见”次数。

预测：

- 有效空间线索提高发现率并缩短发现时间。
- 无效线索相对有效线索表现更差。
- 线索收益在变化区域不完全可预测时仍应存在，但小于完全有效线索。

原文参考：Rensink, O'Regan & Clark (1997), *Psychological Science*, 8(5), 368–373。

## 实验二：安检员：行李 X 光

研究问题：明示目标流行率和不对称奖惩是否分别改变低流行率搜索中的判断标准？

设计：

- 四段被试内条件，每段 20 件行李，正式试次共 80。
- 高流行率参照：50%，10 个目标。
- 低流行率基线：10%，2 个目标，不提前说明流行率。
- 明示流行率：10%，2 个目标，指导语明确告知约 10% 含违禁品。
- 不对称奖惩：10%，2 个目标，不给流行率提示，只展示计分矩阵。
- 明示流行率和奖惩条件绝不合并。
- 练习 4 件行李，包含目标和空行李。

计分矩阵只用于不对称奖惩条件：

| 结果 | 得分 |
|---|---:|
| 查获违禁品 | +1 |
| 正确放行 | +1 |
| 漏报违禁品 | -5 |
| 误报 | -1 |

操作：

- 按 `F`：有违禁品，开包检查。
- 按 `J`：没有违禁品，放行。
- 单件行李最长 3.5 秒；超时视为放行。

因变量：

- 漏报率。
- 误报率。
- 辨别力 `d′`。
- 判断标准 `c`。
- 正确试次反应时。
- 奖惩条件下的平均得分。

预测：

- 低流行率基线的漏报率高于 50% 参照。
- 明示 10% 流行率会使 `c` 下降并减少漏报，误报可能增加。
- 不对称奖惩会使 `c` 进一步下降，减少漏报但提高误报。
- 两种改进条件主要改变判断标准，而 `d′` 不应出现同等幅度的变化。

原文参考：Wolfe, Horowitz & Kenner (2005), *Nature*, 435, 439–440。

## 实验三：估一估：图形直觉排序

研究问题：共同基线是否比非共同基线带来更准确的比例判断？

设计：

- 四种编码：共同基线、非共同基线、角度/饼图、面积/气泡。
- 每种编码 10 试次，共 40 个正式试次。
- 五个真实比例：17.8%、26.1%、46.4%、68.1%、82.5%，每种比例每编码重复两次。
- 练习 2 次，练习显示正确答案。

操作：

1. 观察同时出现的 5 个图形。
2. 判断 B 是 A 的百分之几。
3. 输入 0–100 的数字并按 Enter。
4. 正式阶段不显示正确答案。

因变量：

- 判断值。
- `log2(|判断值 - 真实值| + 1/8)` 误差。
- 反应时。
- 四种编码的误差排序。
- 共同基线与非共同基线的误差差。
- 面积编码的 Stevens 指数。

预测：

- 共同基线的平均误差低于非共同基线。
- 四种编码的误差排序接近：位置 < 长度 < 角度 < 面积。
- 面积编码对小比例的估计可能偏大，Stevens 指数小于 1。

原文参考：Cleveland & McGill (1984), *JASA*, 79(387), 531–554；Heer & Bostock (2010), CHI。

## 眼动采集

- WebGazer + MediaPipe FaceMesh，全部资源本地托管。
- 9 点校准：每个点注视并点击 5 次。
- 5 点验证：只注视，不点击。
- 以约 200 px 作为课堂环境下的校准质量参考阈值。
- 每个实验前进行快速验证。
- 注视坐标约 15 Hz 采样，写入每个试次。
- 上传前将嵌套样本压缩为不超过 500 个数字的扁平数组。
- 摄像头视频只在浏览器本地处理，不上传。
- 鼠标兜底数据统一标记为 `mouse`，不与摄像头数据混算。

## 统计分析

- 每名被试先计算条件均值。
- 被试内条件使用配对差值和 Cohen's `dz`。
- 二分类结果报告发现率、漏报率、误报率和风险差。
- 低流行率实验使用 log-linear 校正计算 `d′` 与 `c`。
- 班级汇总使用匿名数据，读取接口：

```text
GET /api/hw2/data?project=WRFG5G&experiment=实验名
```

- 结果页展示个人结果、当前班级汇总和原文趋势。
- 小样本不把 p 值作为唯一依据，优先报告方向、个体分布和效应量。

## 结果摘要

截至 2026-11-08，三项实验分别有 11、12、10 名有效被试，每人试次数和条件均完整。

- 闪烁找不同：空间线索使平均发现时间缩短 315 ms（Cohen's `dz` = −0.27），但发现率因天花板效应没有提高（98.2% vs 97.3%）。
- 安检搜索：50% / 10% 基线漏报率为 14.2% / 29.2%；明示流行率未降低判断标准；不对称奖惩使 `c` 降低 0.267（`dz` = −0.87），漏报降至 8.3%。
- 图形知觉：误差排序为位置 < 长度 < 角度 < 面积，符合原文；共同基线误差低 0.063（`dz` = 0.17）；面积 Stevens 指数为 0.90。

完整统计、与原文比较和限制见 [RESULTS.md](./RESULTS.md)。

## 已知限制

- 网页眼动精度低于实验室眼动仪，结果按大 AOI 和方向性解释。
- 小样本班级数据不适合作为稳定总体估计。
- 鼠标兜底只能记录光标位置，不能等同于真实注视。
- 不同浏览器、屏幕尺寸和渲染帧率可能影响反应时。
